# linearAlgebraLib
A small and simple linear algebra headerfile which implements class 12 CBSE linear algebra operations in C
## Code Preview
![](assets/codePreview.png)
# Usage 
```
#include "linearAlgebraLib.h"
```
## Compile and Run
```
gcc -std=c23 -Wall -Wextra -lm main.c -o main && ./main
```
## Supported Operations
- Adjoint
- Inverse
- Determinant
- Multiplication
- Dot Product
- Cross Product
- Addition and Subtraction (WIP)
